Web Gamepad — Contenedor Android para juegos web con gamepad táctil.

Incluye:
- WebView con inyección de JavaScript a todos los frames (si está soportado).
- Gamepad táctil en overlay que emula eventos de teclado (keydown/keypress/keyup).
- Modo navegación / modo juego.

Sigue INTEGRATION_GUIDE.md para integrar o compilar.
